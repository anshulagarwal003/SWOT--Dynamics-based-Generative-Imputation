# Data-Driven Reconstruction of Sea Surface Height Anomalies with Diffusion Models

Code, selected model checkpoints, and derived data accompanying the paper
*"When and Where Does Generative AI Imputation Work? Filling Temporal Gaps
with Implications for SWOT Satellite Altimetry"* (Agarwal, 2027).

This repository covers the **reconstruction pipeline**: a 3D U-Net baseline
and a conditional denoising-diffusion model (DDPM) that reconstruct withheld
intermediate sea surface height anomaly (SSHA) frames from two observed
endpoint frames, evaluated with the Continuous Ranked Probability Score
(CRPS) and isotropic power spectral density (PSD) diagnostics.

GMM-based spectral clustering of dynamical regimes (Figures 18–22) and the
hyperparameter-sweep tracking (Figures 32–35) are maintained in a companion
repository: `<CLUSTERING_REPO_LINK>`.

## Setup

```bash
conda env create -f environment.yml
conda activate ssha-diffusion
pip install -e .   # makes src/ modules (data, model, diffusion_code, ...)
                    # importable from scripts/
```

Raw SSH data is not included (~27 GB); see `data/README.md` for the download
link and how to point the pipeline at it.

## Reproducing paper figures without retraining

Figures 17 and 23–31 can be regenerated directly from the precomputed data
already in this repository, with no checkpoints or GPU required:

```bash
cd scripts

# Figure 17: annotated PSD reading guide
python make_psd_reading_guide.py ../data/derived_npz/compare_lat-31.46_lon-119.01_start150_chunk5.npz \
    --out ../figures/fig17_psd_reading_guide.png

# Figures 23-25: reconstruction comparison grids (5/10/21-day gaps)
python compare_models_plot.py ../data/derived_npz/compare_lat-31.46_lon-119.01_start150_chunk5.npz \
    --out ../figures/fig23_compare_5day.png

# Figures 26-28: per-frame CRPS vs. time
python plot_crps_timeseries.py ../data/derived_npz/compare_lat-31.46_lon-119.01_start150_chunk5.npz \
    --out ../figures/fig26_crps_timeseries_5day.png

# Figures 29-31: regime-conditioned seasonal CRPS maps (run the notebook)
jupyter nbconvert --to notebook --execute crps_cluster_mean_plots.ipynb
```

(`crps_cluster_mean_plots.ipynb` expects to be run from `scripts/`, which is
why the commands above `cd` there first; its own cells reference
`../data/regime_labels/` and `../data/derived_crps/` accordingly.)

## Running inference with the provided checkpoints

```bash
python scripts/compare_models.py \
    --unet-ckpt checkpoints/best_models/Unet/chunk5_base8_kT5_bs128_lr1.00e-03_best_model.pt \
    --diffusion-ckpt checkpoints/best_models/Diffusion/ddpm_chunk5_base16_kT5_lr3.00e-04_best.pt \
    --lat -31.46 --lon -119.01 --start 150 \
    --n-ensemble 10 --cold-start-t 700
```

This writes both a combined comparison figure and a `.npz` of the underlying
arrays (ground truth, interpolation, U-Net prediction, diffusion ensemble,
PSD curves, CRPS maps), which `scripts/compare_models_plot.py` can then
restyle without rerunning the models.

## Evaluating CRPS on the full held-out test set

```bash
python src/compute_global_crps.py \
    --diffusion-ckpt checkpoints/best_models/Diffusion/ddpm_chunk5_base16_kT5_lr3.00e-04_best.pt \
    --season summer --out data/derived_crps/crps_results_chunk5_summer.csv
```

## Training from scratch

```bash
python src/train.py --config src/config.yaml
# or, for a W&B hyperparameter sweep:
python src/run_sweep.py --config src/config.yaml
```

Training requires the raw SSH data (see `data/README.md`) and a Weights &
Biases account (`wandb login`) if sweep tracking is desired.

## Data normalization and the SSHA reconstruction task

Each spatiotemporal chunk is normalized in two steps before being seen by
either model: (1) the spatial mean of every individual frame is subtracted,
converting it into a true SSH anomaly (SSHA) field, and (2) the result is
rescaled by a fixed global mean and standard deviation computed once over
the training set (`data.global_mean`, `data.global_std` in
`src/config.yaml`). Reconstruction, CRPS, and PSD figures in this repository
and the paper are reported in these normalized units unless stated
otherwise. See the paper's Methods section (and `src/data.py`) for details.
