# When and Where Does Generative AI Imputation Work?

Code accompanying the S.M. thesis:

> Anshul Agarwal, *When and Where Does Generative AI Imputation Work? Filling
> Temporal Gaps with Implications for SWOT Satellite Altimetry*, S.M. thesis,
> Massachusetts Institute of Technology, 2027.

The thesis asks where and when generative models can fill temporal gaps in sea
surface height (SSH) observations, with implications for SWOT satellite
altimetry. SSH comes from the MITgcm-LLC4320 global ocean simulation, used as
a ground-truth proxy. The work has two stages, each in its own folder:

| Folder | Stage | What it does |
|---|---|---|
| [`Clustering Pipeline/`](Clustering%20Pipeline/) | 1. Regime identification | PCA + Gaussian Mixture Model clustering of wavenumber-frequency SSH spectra into dynamical regimes (e.g. IGW-dominant, MBM-dominant, mixed), run separately for summer and winter. |
| [`Imputation Pipeline/`](Imputation%20Pipeline/) | 2. Gap-filling | A 3D U-Net baseline and a conditional diffusion model (DDPM) that reconstruct withheld intermediate SSH anomaly frames from two observed endpoint frames, evaluated with CRPS and PSD diagnostics. |

The clustering stage motivates the imputation stage. The regime labels it
produces are used to see where gap-filling is easier or harder.

## How the two stages connect

```
LLC4320 SSH spectra ──► Clustering Pipeline ──► regime labels (per location, per season)
                                                        │
LLC4320 SSH frames ──► Imputation Pipeline ◄────────────┘
                        (U-Net / DDPM reconstruction, CRPS & PSD evaluation,
                         regime-conditioned CRPS maps)
```

The cluster assignments and centroid coordinates from stage 1 are included in
`Imputation Pipeline/data/regime_labels/`, so the imputation code runs without
re-running the clustering.

## Repository layout

```
Clustering Pipeline/   GMM spectral clustering (package, CLI, notebooks, tests, example figures)
Imputation Pipeline/   U-Net / diffusion reconstruction (src, scripts, checkpoints, derived data, figures)
paper/                 Thesis paper materials
```

## Getting started

Each folder is self-contained, with its own install steps and usage.

- **Clustering:** see [`Clustering Pipeline/README.md`](Clustering%20Pipeline/README.md).
  Install with `pip install -e ".[dev,notebooks]"` and run the `ssh-clustering` CLI.
- **Imputation:** see [`Imputation Pipeline/README.md`](Imputation%20Pipeline/README.md).
  Create the conda environment from `environment.yml`, then `pip install -e .`.

## Reproducing the paper figures

| Figures | Where |
|---|---|
| 18–22 (regime clustering) | [`Clustering Pipeline/`](Clustering%20Pipeline/), with example output in its `figures/` folder |
| 17, 23–31 (reconstruction, CRPS, PSD) | [`Imputation Pipeline/`](Imputation%20Pipeline/), regenerable from the included derived data with no GPU or retraining |
| 32–35 (hyperparameter sweeps) | Weights & Biases sweep tracking, set up in `Imputation Pipeline/src/run_sweep.py` |
| Other figures | Conceptual diagrams or reproduced from prior work, not generated by this code |

See the Imputation Pipeline README for the full figure-by-figure table.

## Data

The raw SSH data from LLC4320 is large (~27 GB for the imputation stage) and
is **not** included. Each pipeline's `data/README.md` explains how to obtain it
and where to place it. Derived data, selected model checkpoints and example
figures are included so the main results can be inspected without the raw data.
